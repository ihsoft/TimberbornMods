Browse maps without leaving Timberborn

Map Browser adds a main-menu browser for custom maps and public Steam Workshop map metadata.

Use it to inspect installed custom maps, search Workshop maps by keywords and map classifications, preview map details, and subscribe to new maps without restarting the game.

Features

  • Browse installed custom maps with Workshop titles, descriptions, previews, galleries, live statistics, and map dimensions.
  • Search indexed Workshop maps by keywords, forest density, water form, settlement space, islands, canyons, and mountains.
  • Subscribe to Workshop maps from search results or map details without restarting the game.
  • Unsubscribe from Workshop maps or permanently delete local map files.
